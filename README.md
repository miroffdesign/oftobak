# Мактабча — Алифбо

Игра для детей 5–6 лет: ребёнок обводит пальцем буквы таджикского алфавита, слышит звук и получает звёздочки.
Это первый модуль приложения «Мактабча», которое готовит детей к первому классу.

## Что внутри

- Все 35 букв таджикского алфавита с порядком обводки (цифры и стрелки).
- Слово и картинка к каждой букве, название буквы («бе», «ғе», «и-имло»…).
- Проверка обводки: буква засчитывается, если закрашено ≈65% и линия не уходит далеко.
- Звёздочки и прогресс (хранятся на устройстве).
- Раздел «Для взрослых»: можно загрузить записанный звук для каждой буквы.
- Работает без интернета и ставится на телефон как приложение (PWA).

## Как открыть на телефоне

1. Откройте ссылку GitHub Pages этого репозитория в Chrome (Android) или Safari (iPhone).
2. Android: меню ⋮ → «Добавить на главный экран» / «Установить приложение».
   iPhone: кнопка «Поделиться» → «На экран Домой».
3. После первого открытия игра работает без интернета.

## Как включить GitHub Pages

Settings → Pages → Source: «Deploy from a branch» → Branch: `main`, папка `/ (root)` → Save.
Через 1–2 минуты сайт будет доступен по адресу `https://<ваш-логин>.github.io/maktabcha/`.

## Как обновлять

1. Измените файлы (`index.html` и др.).
2. В `sw.js` увеличьте `VERSION` (например, `maktabcha-v2`), иначе телефоны покажут старую версию.
3. Сохраните изменения в `main` — Pages обновится сам.

## Структура

```
index.html             — вся игра (разметка, стили, логика)
manifest.webmanifest   — название, иконки, цвета для установки на телефон
sw.js                  — офлайн-кэш
assets/cat.webp        — маскот
assets/fonts/          — шрифт Nunito (SIL Open Font License, см. OFL.txt)
icons/                 — иконки приложения
```

## Дальше

- Записать озвучку носителем языка и вшить звуки в `assets/audio/`.
- Проверить слова к буквам Е, Ё, И, Й, Э, Ю с учителем.
- Упаковать в Android-приложение через Capacitor и выпустить в Google Play.
